# StockAI 桌面与 Web 共用版

当前版本为 **3.2.1**（2026-11-04）。从 [本版 Release](https://github.com/EdgarLi-Xun/StockAI/releases/tag/v3.2.1) 下载 EXE，并核对同名 `.exe.sha256`。单文件桌面与附属 Web 保持共用工作区，同步、独立 Hub、远程客户端及升级操作见 [同步与升级使用说明](使用说明-同步与升级.md)。先前预览版和 2.0.0 的验收记录保留，本次变更见仓库根目录的更新记录。

双击 `StockAI-3.2.1-Windows.exe` 打开桌面窗口。Python、Qt、后端、网页和加密备份工具均包含在这一个 EXE 内，不需要另装 Python、Node.js 或 Linux 服务。适用于 Windows 10/11 x64。

首次运行会解包运行组件，随后在页面创建本机账号；无需邀请码或验证邮件。账号、模型配置、自选、报告、提醒、日志和实验在桌面与 Web 中共享。模型仍需本人安装 Ollama 或配置个人服务商凭据；安装包不包含模型权重、凭据或示例交易行情。

登录或首次创建账号时，默认勾选「记住登录状态（30天）」，刷新页面、重新打开浏览器或退出并重开客户端后，可恢复有效登录。取消勾选时使用临时会话，最长8小时。主动退出登录、重置密码或账号被停用后，已记住的会话也会失效。桌面与浏览器分别保存各自的登录状态；密码不会保存在网页本地存储中。

如需下次自动填写，可另外勾选「记住用户名和密码」。桌面端在登录成功后写入当前 Windows 用户的凭据管理器，按本机工作区或远程站点/账号配置隔离；密码不进入业务数据库、同步包或网页本地存储。登录页及账号页可清除本机记住的用户名和密码。普通退出保留已选择记住的输入，但不会因此自动提交登录；重置密码后清除本机旧记录。Web 端由支持的浏览器密码管理器保存和管理，也可使用浏览器自带的密码自动填充。

## 打开 Web

桌面左上角菜单及系统托盘均有「打开 Web 版」。它在默认浏览器打开同一个本机后台，不是第二套独立数据。首选地址为 `http://127.0.0.1:8765`，被其他程序占用时自动顺延；以窗口底部显示的端口为准。服务监听 `0.0.0.0`，本机可使用 `127.0.0.1`、`localhost` 或本机局域网 IPv4 地址；同一局域网设备使用 `http://<运行 StockAI 的电脑 IP>:<实际端口>`，并登录已有账号。`0.0.0.0` 是监听地址，浏览器应填写具体 IP。

首次创建账号仍须在运行程序的电脑上通过 `127.0.0.1` 完成。程序只接受启动时识别到的本机地址，保留登录、CSRF 与同源校验；IP 变化后请重启程序。其他设备访问还需 Windows 防火墙允许所用端口，程序不会自动修改系统防火墙。HTTP 入口用于可信局域网，公网部署继续使用独立的 HTTPS Web 服务。

关闭窗口后应用驻留系统托盘，Web 与计划任务仍可使用；托盘「打开桌面」恢复窗口。再次双击同一工作区的 EXE 会激活现有窗口。需要完全停止时，选择菜单或托盘「退出 StockAI（停止本机服务）」。

## 数据位置与升级

数据默认保存在 `%LOCALAPPDATA%\StockAI\workspace`，与 EXE 解包缓存分开；从其他位置运行或替换 EXE 不会重置资料。菜单「打开数据目录」可定位。`data` 存研究数据库与归档，`control` 保存最新删除/用量权威记录，`secrets` 保存主密钥和本机备份身份；保护和迁移时需保留完整工作区。

首次启动自动生成仅在本机保管的 age 备份身份。导出仍需当前账号密码；恢复规则沿用研究工作台的独立权威记录检查。丢失主密钥或控制记录会拒绝启动，不能通过重新生成绕过。

原源码模式及其数据目录保留；本 EXE 使用独立的持久工作区，不自动读取、复制或覆盖旧目录。研究功能见「使用说明-研究工作台与AI助手.md」。

## 构建与验证

开发者在已安装依赖的 Windows 构建环境运行 `python scripts/package-exe.py`。构建工具 PyInstaller 使用 6.22.3；前端构建、运行时资源和采集子进程被一起收集。输出 EXE、SHA-256 与构建元数据到 `dist`；发布包不包含开发账号、数据库、API Key 或主密钥。

实际执行结果登记在「Windows-EXE验收记录.md」。真实行情联网、模型服务与邮件仍按项目既有的外部联调项分别验证。
