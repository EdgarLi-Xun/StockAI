# StockAI 3.2.23

2026-11-21 正式版。

## 本次更新

- 桌面版默认仅允许本机访问。如需从其他设备使用，请在「同步与版本 → 关于与升级 → 桌面与 Web 访问」开启局域网访问并指定允许的私有 IPv4 网段，保存后完全退出并重启桌面服务。
- 完整版报告新增带来源的宏观指标、财务摘要、公告、多周期行情与回测证据。刷新失败时会保留已归档资料并标明缺口。候选和数值继续由程序计算，Ollama 的定性解读在校验失败时重试一次。
- 启用周报后，桌面版可补跑最近一次错过的周度复盘，同时显示原计划日期和实际研究日期。
- 行情同步补充交易所终止上市名单与官方公告核验。缺少日线的证券仍可显示观察报价，预算依据已保存日线计算。
- 切换报告类型时清除上一类列表。模型用量上限发生编辑冲突时，保留草稿并在覆盖前确认。
- 早报和导出附带金银行情、金银比及原始来源。收盘报告逐只对照早报候选，并列出当日模拟信号。
- 排序加入基准相对强弱、风险资料、往返交易成本和风险收益情景。已错过的计划日期留在任务中心，失败任务发站内告警，也可在个人偏好中启用邮件。

## 下载

- Windows 10/11 x64 安装包 `StockAI-3.2.23-Setup.exe`。
- 独立 Web 部署包 `StockAI-3.2.23-Public.zip` 和独立同步 Hub 部署包 `StockAI-3.2.23-Hub.zip`。
- 每个包附同名 `.sha256`。安装包另附构建元数据，两个 ZIP 内含逐文件校验清单。
- 已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。Web 和 Hub 通过各自的部署流程更新。
