## 本轮实现

七项研究增强和项目助手已接入公网 Web 工作台：能力级就绪度、个人调用次数上限、条件提醒、版本化研究日志、组合风险、课题/实验/基准比较、指定报告追问与比较。新增对象均按用户归属读取和写入；模型输入按当前授权重新投影，回答通过校验后才发布。

业务备份之外新增带签名的资源删除与用量权威记录。旧备份恢复会应用最新删除记录和计数，撤销旧凭据，并暂停恢复的提醒；旧待发事件不会自动重发。SMTP 投递线程与提醒评估分离，慢邮件不会阻塞条件检查。

## 确定性业务样本

已核对：一个证券多项缺口只计一个受影响对象；修复当前资料会失效共享缓存，私人最近报告不会跨用户复用，旧报告正文不变。缓存只包含共享证据、证券集合和数值偏好，市场表更新使其失效，时间条件最长 15 秒重新检查；归档报告仍冻结其生成结果。

调用次数按服务端上海日/月窗口计数；剩余一次时并发只允许一次发送；降低上限与跨窗口预留重新核对；不确定发送不释放。已知 Token 小计与未知 usage 分开；迁移保留旧记录中已有的已知 Token。

提醒覆盖首次满足、持续满足、未知恢复、假后再真、冷却、跨午夜免打扰、恢复后已不满足、版本改变、移除自选、到期与不确定邮件。价格、相对收盘变化、风险过期和指定候选失效由程序检查，不产生额外模型调用。

判断之后首次开盘为观察起点，固定第 1/5/20 个交易日；开盘 10、目标收盘 10.50 的观察收益为 5%。100 股按 9.90 买、10.40 卖，双边各费 5 的模拟净收益为 40；部分配对不当作完整闭合收益。

现金 4,000、持仓 6,000 的仓位/现金占比为 60%/40%，冻结 1,000 时可用现金为 3,000，不重复扣权益。已知行业 3,000 占持仓 50%、权益 30%；未知分类 1,000 保留在分母，分类覆盖为 5,000/6,000。权益 10,000→12,000→10,800 的当前及最大回撤均为 10%；缺价/无可靠分母时返回不完整。

实验保留开始后失败和中断，排队取消不计尝试。买入持有保留未投入现金，指数按共同有效区间归一化为 100，样本内外独立起算。删除当前指数缓存后仍可按归档快照复算基准。报告同事实换模型标为解释变化；比较回答同时引用两侧版本并展示程序差异。

助手覆盖固定范围/攻击集、4,000/4,001 码点、上下文裁剪、伪造引用/数字/脚本拒绝、逐配置授权、删除来源、重复客户端标识、断线按序读取、跨日历史追问、停止确认和在途删除不写回。

## Linux 负载测量

环境为现有 WSL2 Ubuntu 22.04 上的断网 Docker 验证容器，Linux 6.6.87.2，Python 3.13.18，SQLite 3.54.1。环境报告 20 个逻辑 CPU、约 15.5 GiB 内存；本批进程峰值 RSS 156,180 KiB。它是开发机的受控 Linux 验证环境，不是用户正式部署主机。

20 个普通负载账号使用 20 份独立登录会话。每人 300 自选、50 提醒、1,000 日记修订、200 实验、100 会话且每会话 200 消息；合计 400,000 条消息。300 个合成共享证券另有程序初始的 7 个公共观察标识，共 18,000 根合成历史日线。当前日历/风险故意保持未知，避免合成资料被标成当前可交易事实。数据库约 335 MiB，夹具生成约 7.7 秒。

| 指标 | 最终测量 | 目标 / 解释 |
| --- | --- | --- |
| 20 独立登录会话并发 HTTP 读取 | 120 请求，P95 **1.897 秒**，最大 2.501 秒 | P95 ≤ 2 秒；读取就绪度与会话列表 |
| 各普通接口顺序读取 | 10 类接口各 5 次，最大分组 P95 **0.221 秒** | ≤ 2 秒；含结果/修订与列表 |
| 混合任务受理 | 20 个报告/对话/连接测试，P95 **0.107 秒** | ≤ 1 秒；受理与推理分离 |
| 停止确认 | **0.037 秒** | ≤ 1 秒；不承诺供应商终止计费 |
| 模型并发 | 本批观测峰值 1，上限 2；20 位用户均获调度 | 更早双并发回归也验证了 2 个槽位限制 |
| 全部 1,000 提醒的一轮评估 | **23.231 秒** | 周期另等待 15 秒；邮件不占评估线程 |
| HTTP 失败率 | 0 | 控制内的请求均返回预期成功状态 |

原始结果：[脱敏 JSON](evidence/research-2026-11-02/historical-load.json)。测试模型固定延迟 50ms；报告使用冻结的最小事实以测队列和调用边界，不能把这项结果解释为 300 只证券完整报告的生成耗时或真实供应商延迟。HTTP 使用 TestClient/ASGI 往返，包含权限检查和响应序列化，不包含生产反向代理、TLS、互联网时延或真实行情采集。

首次并发内部读取曾出现 P95 13.12 秒。修复共享证据重复扫描后，独立登录 HTTP 测试又暴露了诊断快照写入和全量响应开销；通过共享失效缓存、合并连接查询及分页返回修复，保留原阈值完成上述最终测试。
