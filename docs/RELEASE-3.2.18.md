# StockAI 3.2.18

2026-11-11，正式版。此次把桌面里的新窗口外链交给系统浏览器。

## 桌面外链

公告和来源如果要求新窗口打开，会交给系统浏览器。应用窗口保持不动，同一链接只打开一次。远程窗口只接受 https 外链。

## 下载

- Windows 10/11 x64：`StockAI-3.2.18-Setup.exe`。
- 独立 Web：`StockAI-3.2.18-Public.zip`；独立同步 Hub：`StockAI-3.2.18-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
