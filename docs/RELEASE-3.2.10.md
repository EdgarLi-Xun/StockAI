# StockAI 3.2.10

2026-11-05，正式版。此次整理想法池与邮件页，并让自选置顶和助手上下文立刻跟上当前操作。

## 想法池与邮件发送

想法池按卡片展示证券名称、进场、离场、错在哪和写入时间。空池和读取失败会直接说明原因。邮件发送页分栏填写服务器和发信身份，并标明当前是否正在发信；普通账号看到管理员配置说明。

## 置顶与助手窗口

点击自选置顶后立刻更新当前列表，不再等整页总览刷新。助手上下文预算按模型窗口计算，不再卡在固定 8000 字节上限。

## 下载

- Windows 10/11 x64：`StockAI-3.2.10-Setup.exe`。
- 独立 Web：`StockAI-3.2.10-Public.zip`；独立同步 Hub：`StockAI-3.2.10-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
