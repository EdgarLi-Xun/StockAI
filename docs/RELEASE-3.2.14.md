# StockAI 3.2.14

2026-11-10，正式版。此次加入模拟价格规则，并重做今日总览。

## 模拟价格规则

模拟账户可以启用四种规则：收盘落到后买入、收盘升到后卖出、收盘止损、均线向前跟随。规则只看已完成日线，条件成立后生成限价委托。成交仍按下一根日线开盘，并继续检查涨跌停、费用、T+1 和单只含费预算。不连接真实证券账户。想法池可以把一条想法预填成规则。

## 今日总览

总览改为研究简报，展示行情覆盖、核验通过、候选名额和市场脉搏。指数可切换最近 30 期或 90 期。切换指数或连续打开报告时，后返回的旧请求不再覆盖当前页面。浅色与深色背景改为偏绿的纸色。

## 桌面调试

调试桌面程序时留在当前进程，不再立刻交给已安装版本并退出。

## 下载

- Windows 10/11 x64：`StockAI-3.2.14-Setup.exe`。
- 独立 Web：`StockAI-3.2.14-Public.zip`；独立同步 Hub：`StockAI-3.2.14-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
