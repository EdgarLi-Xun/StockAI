# StockAI 3.2.11

2026-11-05，正式版。此次让助手直接读取已记录持仓，并让桌面升级下载失败后可以重试。

## 现有持仓

问到现有持仓时，助手读取已记录的持仓价、数量和按已存行情现算的金额收益。未记录时返回空列表，不编造价格或数量。点开单只证券来源时，已填写的持仓也会一并展示。

## 升级下载

下载遇到意外错误会标为可重试的网络失败，当前程序不变。下载请求中断后仍会等待进行中的安装包。Windows 下升级状态读写不再把同进程排队误判成第二个服务。

## 下载

- Windows 10/11 x64：`StockAI-3.2.11-Setup.exe`。
- 独立 Web：`StockAI-3.2.11-Public.zip`；独立同步 Hub：`StockAI-3.2.11-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
