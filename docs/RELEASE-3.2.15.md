# StockAI 3.2.15

2026-11-10，正式版。此次让软件内升级完成后自动换成新版本。

## 软件内升级

升级完成后，旧桌面程序退出，新版本替换正在运行的实例。程序目录仍被占用时会重试替换。升级页在新版本尚未打开时显示「正在退出并打开新版本」。

## 今日总览

自选卡片可以直接进入自选列表。从报告详情用浏览器后退时，会回到报告列表。

## 下载

- Windows 10/11 x64：`StockAI-3.2.15-Setup.exe`。
- 独立 Web：`StockAI-3.2.15-Public.zip`；独立同步 Hub：`StockAI-3.2.15-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
