# StockAI 本地版验收记录

验收日期：2026-11-01，Asia/Shanghai。

本轮按原始 V2.0 PRD 实现本地版本。开发期间新增的 MiniMax、个人模型配置与登录注册决策，经用户确认列入下一轮，保留在 ADR 中。

## 本机结果

- Python 自动回归：**84 项通过**，耗时 83.56 秒。测试数据与数据库全部隔离，人工构造样本未写入实际研究库。
- Vue/TypeScript 类型检查与 Vite 生产构建通过。
- PySide6/Qt WebEngine 桌面入口冒烟测试输出 `DESKTOP_SMOKE=PASS`，载入与浏览器相同的本地页面。无显示环境中 Chromium 打印 GPU 回退信息，加载测试通过；没有将该测试当作真实硬件视觉验收。
- 浏览器验证：证券搜索、真实K线、指标、预算试算、两种报告入口、任务日志；手机 390×844 与桌面 1440×1000 视口均未出现页面横向溢出。
- 实际观察池 43 项，其中 42 项具有行情或净值记录。记录包括历史或延迟报价，不代表全部为实时或可交易数据。未核验证券均被排除，当前候选为零。
- 国际黄金、白银与沪金、沪银四条真实报价均具有来源、币种、单位和报价时间，周末旧报价标记过期。三只场外基金净值单独保存，不能按股票规则模拟交易。
- 标准版与完整版各归档一份。标准版演示输出校验失败后的规则降级；完整版成功使用本机 `qwen3-14b-16k:latest`，通过结构与事实边界校验。
- 真实历史实验使用 527 根已保存日线，执行 37 次模拟成交；结果明确标为**未验证实验**，保留历史风险状态和公司行动证据缺口。快照重演的交易、样本外及费用敏感性结果一致。
- 实际创建一个校验通过的备份，包含 43 个观察项目、2 份报告、1 次回测实验。模拟账户与模拟委托仍为空，未为用户预设总资产。

## 外部条件与验证范围

港股观察源返回历史零值/OHLC冲突，本轮保留不可用状态。部分东方财富、宏观与基本资料接口返回空内容或非 JSON，日志记录原始错误类型与数据缺口，备用渠道只接收有效数据。

交易所列表只能核对名称，不能证明停复牌或公告安全。因此本轮未批量把证券设为可交易；需要用户在详情实际核对官方证据后记录结论。免费日线缺少逐日历史风险及公司行动资料，严格回测应拒绝；未验证实验不能当作可靠策略收益。

尚未在另一台 Windows 10 设备完成全新安装、升级、卸载，也未启用实际局域网访问、注册系统登录任务或配置邮件密码。物理休眠唤醒、跨设备防火墙/TLS 与真实 SMTP 发送应在目标环境验收。这些结果没有计入已通过测试。

当前测试工具产生一项 Starlette TestClient 关于 httpx 迁移的弃用提示，不影响现有 84 项结果。本机完整版本记录保存在 `requirements-windows-verified.lock`，前端依赖有 `package-lock.json`。
