# StockAI 3.2.7

2026-11-05，正式版。此次调整自选顺序，并在总览中展开持仓收益。

## 自选顺序

已记录持仓价和持仓数量的证券排在仅置顶的收藏之前。同时持仓并置顶的在最前，其次是仅持仓，再次是仅置顶，其余保持原来的分组和代码顺序。今日总览、自选证券和市场行情使用同一顺序。

## 总览持仓

公网总览的自选表列出持仓价、持仓数量、持仓金额、当天收益、当天收益率、总收益和总收益率。金额和收益按已存日 K 与记录成本现算，不含费用；缺少行情时保留「—」。列较多时表格可以横向滚动。

## 下载

- Windows 10/11 x64：`StockAI-3.2.7-Setup.exe`。
- 独立 Web：`StockAI-3.2.7-Public.zip`；独立同步 Hub：`StockAI-3.2.7-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
