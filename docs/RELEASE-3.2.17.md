# StockAI 3.2.17

2026-11-11，正式版。此次加入最新价，并让模拟规则可以按最新价触发。

## 最新价

自选、总览和证券图显示最新价，图上补当天这一根。已完成日线不改写，研究仍用收盘。持仓收益优先用最近价，没有最近价时用已存日 K。

打开 15 分或 60 分时，会自动更新正在查看的分钟图。

## 模拟与提醒

价格规则在最新价穿过条件时当天生成委托。限价到达后可按最新价撮合；没到价仍留到后续日线。

条件提醒可以相对昨收，也可以上穿或跌破均线。

## 下载

- Windows 10/11 x64：`StockAI-3.2.17-Setup.exe`。
- 独立 Web：`StockAI-3.2.17-Public.zip`；独立同步 Hub：`StockAI-3.2.17-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
