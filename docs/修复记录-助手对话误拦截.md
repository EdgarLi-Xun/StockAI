# 助手对话误拦截修复记录

版本：3.2.0-preview.2；修复验证：2026-11-02；交付整理：2026-11-03。状态：DONE，本次问候与项目追问误拦截已修复并验证。

## 问题与根因

用户在桌面项目助手连续发送“你好”，两次都收到“请附带具体资料”的提示。后台将问候、继续追问和含糊研究请求放进同一个正则，并在检查已选资料之前返回澄清；普通项目追问也没有结合仍被当前权限允许的历史判断话题。

## 修复后的行为

- 问候和入门问题无需先选择账户、报告或证券。有选定模型时进入正常个人队列和模型调用；未配置模型时显示明确标注的项目欢迎帮助及配置入口。
- “分析一下”“帮我分析这只股票”等带明确资料的问题可以进入研究解释，不再被前置拦截。
- “继续”等项目帮助追问使用允许的近期历史和当前知识条目。当前问题、引用和回答仍经过原有校验。
- 清除研究对象后，不从历史偷偷重新附带该对象；缺资料、跨用户 ID、撤销授权、凭据和范围外请求的保护继续生效。
