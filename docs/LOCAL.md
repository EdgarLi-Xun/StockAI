# StockAI 本地版使用指南

StockAI 按目录内 V2.0 PRD 开发，Windows 桌面端与 Web 端共用 FastAPI、SQLite 和一套 Vue 页面。支持标准版早报、完整版复盘、行情观察、模拟交易与可复演的历史回测。所有操作均为研究或模拟，没有真实证券账户或下单接口。安装入口与源码开发说明见 [项目首页](../README.md)。

新增的 **3.0 公网多用户版**使用独立入口、数据目录和个人账号，支持 MiniMax、多套个人模型配置、邀请注册、任务队列及加密备份。部署与迁移参阅 [公网版说明](../deploy/cloud/README.md)，验证范围参阅 [公网版验收记录](验收记录-公网多用户与模型接入.md)。下文继续说明原有本地版。

## 在本机运行

安装依赖并完成前端构建后，双击 **Start-StockAI.cmd** 打开桌面窗口，或双击 **Start-Web.cmd** 打开浏览器。两者使用相同的 [本地地址](http://127.0.0.1:8765)。默认只监听 `127.0.0.1:8765`。

首次在另一台 Windows 机器安装：

1. 安装标准版 Python 3.11、3.12 或 3.13，包含 Python Launcher。开发验证使用 Python 3.13。不要选择 free-threaded Python。
2. 解压发行 ZIP，双击 **Install-StockAI.cmd**。脚本在项目 `.venv` 中安装依赖，不修改系统 Python 包。发行包包含已构建网页，正常安装不需要 Node.js。
3. 双击桌面或 Web 入口。关闭桌面窗口后，共享后台服务继续运行，让浏览器和计划任务仍可使用。

源码前端开发需要 Node.js 22.12+（本机已使用 Node 24 验证）。在 `frontend` 中运行 `npm ci`、`npm run dev`，开发地址为 `http://127.0.0.1:5173`，API 代理至 8765。生产构建运行 `npm run build`。

手动启动后端：

```powershell
.\.venv\Scripts\python.exe run.py --serve
```

停止服务：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\stop.ps1
```

## 首次研究

1. 在本机启动 Ollama，确保 `http://127.0.0.1:11434/api/tags` 包含 `qwen3-14b-16k:latest`。可在设置中修改本机地址和模型名称。
2. 在“系统设置”核对券商费率。默认佣金、最低佣金、过户费、卖出印花税与滑点均明确标注为**模拟假设**，不视为用户真实费用。ETF 单独配置费用，不套用股票税费。
3. 点击“同步数据”。初始观察池包含 PRD 中的 43 个股票、ETF、指数、贵金属和独立观察项目。初始名称仅作历史备注，未核验状态不会进入候选。
4. 在证券详情打开官方上市、停复牌、公告和交易规则来源，实际核查后保存证据与结论。名称同步不会自动把公告未知变成安全。证据默认有效 24 小时。
5. 生成标准版报告，或在周度复盘生成完整版。候选可以为零。断网、风险未知、交易日历不覆盖、报价过期或费用后超预算时会排除对应证券。

普通股票一手 `100 × 9.99 + 5 = 1004` 元，预算校验拒绝；`100 × 9.90 + 5 = 995` 元仅通过预算门槛。启用过户费时还会计入配置的过户费。产品交易单位、数量阶梯、价格步长、T+0/T+1 和涨跌幅须逐产品核验。

## 数据与模型边界

- A 股/ETF/指数：AKShare 的东方财富主源与新浪备用源；增量日线缓存，支持可取得的 15 分钟与 60 分钟K线。实际采集接口以 [AKShare 官方文档](https://akshare.akfamily.xyz/data/stock/stock.html) 为依据。
- 官方名称：上交所、深交所列表渠道。公告使用巨潮资讯适配器；自动发现风险公告会阻止入选，但“没有抓到公告”不会被解释为安全。
- 国际黄金、白银：新浪外盘报价，经 AKShare 接入。沪金、沪银：保留新浪原始报价的日期和时间。现货与期货连续合约、美元/盎司与人民币/克/千克分别展示。
- 完整版尝试获取经济指标、个股基本资料和公告。第三方宏观与基本资料会标记来源和未作官方财务核验，无法取得的行业/宏观/财报证据明确列为缺失。
- 港股、美股与场外基金仅供独立观察，不参与普通模拟买入。免费渠道不保证覆盖所有代码；无可用数据就显示不可用。
- Ollama 按 [官方 Chat API](https://docs.ollama.com/api/chat) 使用 JSON Schema、非流式输出与本地模型互斥。程序持有价格、预算、数量、交易资格及来源；AI 仅写定性解释，解释中不允许数字事实，所有数值由程序展示。
- 模型离线、输出无效或显存紧张时，重试一次或退化为规则报告。错误输出不会写入研究记录。未运行回测时不估算回测收益。

## 模拟账户与回测

在“模拟交易”中自行填写虚拟初始资金，创建限价委托。买入含费总成本不超过单只预算，待成交买单预留现金，卖单预留数量。页面同时显示待买已预留和还可再买。仅在委托创建之后的完整日线开盘进行保守撮合，检查价格范围、涨跌停、停牌与 T+1。盘中提交的委托不会倒用当天早盘价格。收盘止损生成后续待成交委托，不保证按止损价成交。

价格规则有四种：收盘落到后买入、收盘升到后卖出、收盘止损卖出、均线向前跟随。规则只用已完成日线。北京时间 15:00 之前启用，当天收盘可以发信号；15:00 及之后启用，当天收盘不采用。信号生成限价委托，最早在下一根开盘撮合。均线跟随使用与回测相同的短长均线和收盘止损比例，但从启用之后才向前生成委托，不会把回测里的历史成交写入模拟账户。候选、想法和回测只预填表单，确认后才启用。想法里的句子不会被解析成价格。

回测采用等价的 Python 确定性引擎，策略版本化；使用不复权成交价、收盘信号和下一根开盘撮合。支持费用、滑点、合法数量、T+1、涨跌停、零成交量、分红/拆分事件、样本内外划分、费用敏感性、交易流水、回撤和完整数据快照。

严格回测需要逐日历史风险状态、限价和公司行动证据。普通免费日线没有这些字段时，严格模式拒绝验证；可显式取消严格模式运行**未验证实验**，所有缺口随结果持久保存。固定自选池存在幸存者偏差；结果不会被标成全市场有效策略。

历史数据可在证券详情导入 JSON 数组。字段与证据格式见 [历史导入说明](HISTORICAL-DATA.md)。回测结果保存行情、规则、费率、参数、策略版本与 SHA256，使用“快照重演”可核对完整交易与样本外结果一致性。

## 调度和通知

唯一研究调度源为内建调度器，统一 `Asia/Shanghai`：每天 08:00 标准版、经交易日历核验的交易日 16:00 收盘跟踪、周日 20:00 完整版复盘与备份。服务运行后每 30 秒检查。恢复运行后补跑当天到期任务，同一逻辑键不会重复归档；历史已发布早报不会被收盘更新改写。

可选注册 Windows 登录启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\register-startup.ps1
# 取消：在命令末尾添加 -Unregister
```

Windows 任务计划仅启动服务，不再注册第二套早报/复盘触发器。需要保持用户登录且主机唤醒；已关机时不能执行。更早日期的缺报不会伪造为当日历史报告，重试保留原幂等键并展示实际采集时间。

界面保存任务通知。邮件通知需在设置中填写 SMTP SSL 服务器、用户与收件人，凭据仅由进程环境变量 `STOCKAI_SMTP_PASSWORD` 读取；配置不完整不发送。未配置时开发测试不会发送邮件。

## 安全访问

默认局域网关闭。若需要手机访问，在本机设置至少 12 位管理员密码、允许的私有 CIDR，并显式启用 LAN，再重启服务。只读角色仅能读取研究页面；备份下载仅限管理员。密码以 PBKDF2 保存，会话限时、登录限速；API 防跨站与 DNS 重绑定。

内网 HTTPS 反向代理的配置示例见 [反向代理说明](LAN.md)。带代理头的请求始终要求局域网登录，不能通过回环代理获取本机管理员令牌。不要转发 Ollama 的原始端口。

## 备份 升级 卸载

“系统设置”可备份与恢复 SQLite、配置、自选、报告及回测快照，下载 ZIP，并导出/导入配置。恢复必须键入确认文字；程序校验哈希、数据库完整性、记录数量和关联关系，并自动保留恢复前备份。

离线备份脚本：`.\.venv\Scripts\python.exe scripts\backup.py`。离线恢复需先停止服务，再运行 `.\.venv\Scripts\python.exe scripts\backup.py --restore <备份ID> --confirm 恢复备份`。API 入口用于在线受保护恢复。

升级前先备份并停止服务，再替换源码与前端静态资源、重新运行安装脚本。不要覆盖 `data`。数据库启动时执行幂等 schema 初始化；当前数据库结构版本为 1。

卸载：运行 `scripts/uninstall.ps1`，停止服务并取消登录启动；默认保留全部数据。可选 `-RemoveRuntime` 经确认后移除可重新安装的依赖。需要迁移数据时先下载备份。

## 验证与发行

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest
npm --prefix frontend run build
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\package.ps1
```

发行输出：`dist/StockAI-2.0.0-Windows.zip`，包含源码、预构建网页、安装与启动入口及文档，不包含运行时数据库、报告归档、凭据、虚拟环境或依赖缓存。实际验证记录与尚需在其他设备核验的项目见 [验收记录](ACCEPTANCE.md)。

源码布局：`backend` 业务/API/采集/风险/AI/回测/任务，`frontend` 共享页面，`desktop` Qt 壳，`config` 提示模板及示例配置，`scripts` 安装/启动/备份/发行，`tests` 隔离测试。原始 PRD 文件保留不变，提取正文在 `prd-extracted.md`。
