# StockAI 3.2.4

2026-11-04，正式版。界面参考 Trail 的清晰布局，结合 StockAI 已有研究、自选持仓、助手和数据来源功能重新组织。

## 主要更新

- 常用导航从 18 项归为 9 项，相关页面改用子导航；原页面地址继续可用，手机增加底部常用入口。
- 总览集中显示自选、ETF 持仓、收益、数据缺口、市场与最近报告。行情和研究缺失时如实留空。
- 证券详情成为完整工作区：宽屏自选列表、图表与右侧助手并排，窄屏使用证券选择框；保留周期、指标、来源核验、公告、历史导入和含费预算。
- 助手模型选择置于面板顶部，草稿和引用在切页、收起和独立页往返时保留；切换证券不会自动替换已附加的资料。
- 保存官方核验后刷新详情；旧请求、预算和尚在读取的行情文件不会影响后续选择的证券。
- 助手缺少持仓价或数量时先追问，非整数数量不准备写入方案；整数型小数数量可规范处理，仍需本人核对并点击应用。

实际界面、合成数据说明和响应式验收见 [改版实施记录](实施记录-Trail风格工作台改版.md)。

## 下载与更新

- Windows 10/11 x64：下载 `StockAI-3.2.4-Setup.exe`，运行后从开始菜单打开；安装到当前用户的 `%LOCALAPPDATA%\Programs\StockAI`。
- 独立 Web：`StockAI-3.2.4-Public.zip`；独立同步 Hub：`StockAI-3.2.4-Hub.zip`。
- 每个发行包附同名 `.sha256`，安装包另附 `.exe.build.json`，两个 ZIP 含逐文件校验清单。
- 已安装的桌面版可在「同步与版本 → 关于与升级」检查新版，或手动运行安装包。3.2.2 及之前的单文件版需先退出旧程序，再手动安装。
- 研究数据仍在独立工作区，安装目录与数据目录分开。Web 与 Hub 使用各自部署流程更新。

## 构建与验证方式

沿用项目现有 `package-exe.py`、`package-cloud.py` 和 `package-hub.py`。前端同时构建本地版与 Web 版；安装包由 PyInstaller 目录包和 Inno Setup 6 生成。正式版本统一取 `backend/cloud/__init__.py`，旧源码本地入口的 2.0.0 包元信息按原约定保留。

发布检查包含后端回归、54 项前端测试、生产构建、归档逐文件哈希、前端资源指纹、安装包版本及 SHA-256、隔离工作区中的冻结程序与 Qt 页面检查。检查使用合成数据和测试传输，不读取正式个人工作区。实际构建结果与测试统计附于 GitHub Release。
