日期：2026-11-03，Asia/Shanghai。此版本为 GitHub 预览版，累计交付 v2.0.0 之后的研究工作台、AI 助手、单文件桌面、同步和升级功能。原源码本地版的 2.0.0 包元信息与独立数据目录继续保留。

| 文件 | 用途 |

下载地址：[v3.2.0-preview.3 Release](https://github.com/EdgarLi-Xun/StockAI/releases/tag/v3.2.0-preview.3)。源码与构建资源不包含个人数据库、真实模型凭据、会话、主密钥或离线发布私钥。

## 本次发布前修复

- 研究日志、实验等页面冻结本次请求参数并核对请求代次，旧响应、旧错误及过期的后续请求不再覆盖当前页面。
- 还原旧业务备份后，同步恢复优先遵守独立删除权威记录；显式恢复与其当前删除标记关联并记入签名账本。
- 同用户的同步密钥轮换与同步操作使用同一互斥锁，防止并发轮换破坏当前密钥指针。
- 签名更新源的候选逐项验证与最终选定目标的防回放记录分开处理，避免候选列表顺序造成错误拒绝。
- 自动报告与提醒的远端执行协调移出业务数据库写事务，避免慢同步服务阻塞其他用户；任务领取遇到临时数据库锁时可重试。
- 同步提醒邮件仅在 SMTP 明确拒绝接收时开放受控重试；已接受后的退出异常和结果不确定的发送不自动重发。

发布验证的最终结果及文件摘要登记在 [本次证据](https://github.com/EdgarLi-Xun/StockAI/blob/v3.2.0-preview.3/docs/evidence/release-3.2.0-preview.3/artifacts.json)。摘要单独保存在版本标签中，避免把归档自身摘要递归打入发行 ZIP。先前版本的历史证据保留，不能代替本次最终源码和发行文件的验证。

## 安装与升级

Windows 用户退出旧版后运行新 EXE，默认工作区仍为 `%LOCALAPPDATA%\StockAI\workspace`。桌面版不自动读取或迁移原源码本地版的项目 `data/`。更换前可通过原有功能备份完整工作区，操作见 [桌面使用说明](Windows-EXE使用说明.md)。

Web 与 Hub 分别按 [Web 部署指南](../deploy/cloud/README.md) 和 [Hub 部署指南](../deploy/hub/README.md) 部署。发布 GitHub Release 不会自动更新任何服务器。

SHA256 仅用于文件完整性核对。项目没有附带生产签名更新源或发布信任根，GitHub 下载不能绕过应用内的可信根与签名检查，也不能被显示为已完成受控在线升级。
