# 模型配置与默认选择归属于登录用户

2026-11-01，用户确认首家云端模型服务接入 MiniMax，保留本地 Ollama，并允许保存多套模型配置、选择默认配置；同时明确新增登录注册，让每个人管理自己的模型配置。因此，模型配置、其中的访问凭据及默认选择归属于各自登录用户，而不沿用现有的全站共享设置边界，以支持不同使用者独立选择服务并使用自己的凭据。

现有系统只有管理员与只读者两个共享角色，尚无个人登录身份。后续已确认公网服务和个人研究数据边界，见 [ADR-0002](0002-public-multi-user-research-boundary.md)；注册采用邀请码、邮箱与密码，提供邮箱验证和邮件找回密码。自动 AI 调用新用户默认关闭，本人开启后可在退出登录后继续使用自己的默认配置与凭据；失败时生成标明原因的规则报告，不自动切换配置，恢复后可主动补充 AI 并保留版本。已确认的个人调度、配置变更及调用限制见 [新增需求文档第 7 节](../PRD-公网多用户与模型接入.md#7-自动任务)。
