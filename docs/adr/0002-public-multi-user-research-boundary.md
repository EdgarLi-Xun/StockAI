# 公网多用户服务中的个人研究与共享资料边界

2026-11-01，用户确认目标是可从公网访问的多用户服务，并选择让每个人的自选、报告、模拟账户与持仓、回测等个人研究数据独立归属，公开行情和证券基础资料则共享。该边界取代现有单人终端的全站共享研究数据模式，使使用者能够共用市场资料，同时独立维护自己的研究内容。

这项选择意味着现有报告复用、研究记录查询、模拟交易和任务归属需要适应个人研究空间，不能把仅隔离模型 Key 视为已满足多用户要求。随后用户确认：原有私人研究数据迁给初始化时指定的管理员；云模型默认只接收自选、候选和去除身份信息的研究摘要，模拟账户汇总与逐笔成交按模型配置分别主动授权；首发为单台 Linux 云服务器，以 20 个账号、2 人同时生成报告作为验收目标。后台管理访问边界见 [ADR-0003](0003-site-administration-access-boundary.md)，注销与备份保留规则见 [ADR-0004](0004-account-erasure-and-backup-restoration.md)。

本需求集中维护于独立的 [新增需求文档](../PRD-公网多用户与模型接入.md)。
