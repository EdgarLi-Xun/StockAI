# 站点管理角色与个人研究访问分开

用户在 Q14 确认，站点管理员管理账号、邀请码、共享行情、风险核验及站点运维，但后台不提供查看他人私人报告、持仓或完整 Key 的入口。沿用现有管理员可读取全部研究数据的方式较简单，但会破坏本次多人独立研究空间的产品边界，因此站点管理身份不被视为所有私人研究内容的所有者。

该决策限制应用内的访问功能，不承诺服务器运维者在技术上无法接触底层数据。用户在 Q20 进一步确认，管理员再次验证密码后可以导出含全站数据的加密备份，备份保留 30 天；注销与恢复规则见 [ADR-0004](0004-account-erasure-and-backup-restoration.md)。
