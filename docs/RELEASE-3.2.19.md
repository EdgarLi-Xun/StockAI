# StockAI 3.2.19

2026-11-14，正式版。本次调整研究总览与导航样式，修复手机自选列表及升级状态提示。

## 本次更新

- 今日总览采用主次双栏，集中展示市场指数与自选列表；研究提示、就绪情况和最近报告位于侧栏，并随窗口宽度调整布局。
- 浅色背景、导航、按钮及面板样式统一调整。
- 手机自选列表保留筛选栏，表格在页面内独立滚动。
- 只有仍运行旧版本的桌面客户端在升级成功后显示「正在退出并打开新版本」。Web 页面和已运行更新版本的客户端不再因历史升级记录误报正在重启。
- 补充升级提示回归测试，稳定验证多账号凭据隔离与双任务并发。

## 下载

- Windows 10/11 x64：`StockAI-3.2.19-Setup.exe`。
- 独立 Web：`StockAI-3.2.19-Public.zip`；独立同步 Hub：`StockAI-3.2.19-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
- Web / Hub 仍通过各自部署流程更新。
