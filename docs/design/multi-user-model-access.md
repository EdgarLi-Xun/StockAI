## 代码调查事实

- 现有认证只有管理员和只读者两个角色共用密码，令牌仅含角色，本机还会自动获取管理员身份；尚无个人用户与注册流程（`backend/security.py`、`backend/app.py`）。
- 业务表与报告、任务去重键均为全站范围；个人模型默认选择会影响任务执行者、报告复用与请求额度的归属（`backend/db.py`、`backend/jobs.py`）。
- 现有 `facts` 会包含个人研究选择、预算、人工备注；完整版还含模拟账户名、现金与逐笔成交。当前模型调用直接发送整个对象，需在接云端前明确对外数据范围（`backend/research.py`、`backend/ai.py`）。
- 设置读取与配置导出会返回普通设置；备份包含整个数据库。凭据不能直接作为可回读的普通设置字段加入（`backend/app.py`、`backend/maintenance.py`）。
- 现有部署面向单进程 Windows 本机及可信局域网，尚无公网多用户部署交付物；当前进程内会话、调度和任务队列不能直接作为多实例机制（`docs/LAN.md`、`backend/security.py`、`backend/jobs.py`）。
