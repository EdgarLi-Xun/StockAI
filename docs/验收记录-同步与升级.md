# 同步与升级验收记录

日期：2026-11-02。版本：3.2.0-preview.1。依据新增同步 PRD v1.1 与升级 PRD v1.0，两组各 32 项。原研究工作台、AI 助手及桌面 3.1 的历史结论未改写。

## 本轮结论

已形成可执行的预览版本：本机 EXE 与附属 Web、独立 Web/Hub 部署包、远程桌面客户端、加密增量同步、冲突/墓碑/恢复点、账本与执行代次、共享额度，以及验签、预检、独立探针和受控恢复流程。

受控测试通过不等于两份 PRD 的全部实机场景完成。实际 NAS、跨机器长时间断网、目标 Linux/Docker 部署和生产签名更新源尚未提供，以下明确保留待验项。当前不会把配置、下载或预检显示为“已安装”。

## 已验证的关键边界

- AES-GCM 绑定空间、对象类型与密钥代次；错误密钥或篡改不导入。凭据不进入业务包，模型描述到另一端保持未连接，当前本端授权不会被同步扩展。
- 首次合并必须匹配最新预览；先保留本人加密恢复点。独立 outbox 命名空间避免解绑后旧空间密文进入新空间。
- 父版本 DAG 识别并发；共同基线与双方均保留。不可变归档不覆盖；显式恢复生成新版本，墓碑长期保留。
- 模拟账户整批事务应用；收到的待成交委托不撮合。在线写入权转移、旧代次冻结、不合并现金；自动任务需核验执行归属，结果不明不自动重发。
- 最后一次共享额度竞争最多一方领取；模型真实发送前调用此控制。相同调用 ID 不重复发送；有限额离线暂停，不限额本地调用保留未确认记录。新上限等待所有有效设备确认并先补记离线调用。
- Hub 授权码过期/单次消费、跨账号隔离、设备撤销及停用账号均在服务端核验；索引回退与事务提交中断不恢复已消费授权。
- 后端迁移封存旧空间后启用新空间；资料标识、墓碑、用量及代次保留；目标确认丢失可继续同一计划。返回旧设备经过两次后端迁移仍保留原本地 ID，离线旧编辑不能复活删除记录。
- Hub 提供空间内有界游标分页与持久确认；重复上传不产生新变更，旧 SQLite 索引恢复不回退确认。当前和已解绑 Hub 空间的账号注销清理及本机私有材料删除已通过端到端接口验证。
- 可信根、阈值签名、根双重授权轮换、过期/重放拒绝、平台/形态/来源版本匹配均已测试。普通更新不隐式降级。
- 检查点真实加密后解密核验；不存在的数据库不会被创建为空白“备份”。升级失败恢复当前工作区并重施最新控制；开放新版写入后先保存当前状态，再明确阻止不安全覆盖。
- 归档验证包含 Windows 设备名、尾随空格/点、大小写别名、路径越界和符号链接。预检包含实际解包量、备份验证暂存和独立数据卷空间。
- 前端摘要按最终写盘字节生成，覆盖 HTML、CSS、JS 与公共资源；实际冻结探针曾检出生成时机错误，已修正并由最终 EXE 验证。升级终态重复预检不重开事务，重复回滚不覆盖回滚后新增资料。
- 升级缓存按签名事务归属清理，拒绝链接越界，保留当前和可用旧代码；终态数据检查点按 30 天过期并更新回退能力，未完成事务暂缓清理。
- 浏览器未配置更新源时显示检查失败，无效清单不能准备安装；离开未处理输入会提示且取消后保留输入。页面在 1440 与 390 宽度验证。

## 待验与实现边界

1. 真实 NAS/WebDAV 产品与自定义 CA、代理、配额、存储耗尽和网络中断。当前只证明受控真实 TLS 服务与故障测试中的行为，不代表所有 NAS 均兼容。
2. 桌面远程模式在目标 HTTPS Web 的实际登录、切换账号/站点、多机运行与隔离；已验证 URL/缓存命名、无本机业务 Host 的代码路径及独立客户端升级探针，未取得目标远程站点。
3. 独立 Web/Hub Docker 镜像实际构建、持久卷权限、生产域名证书、同机/分机启动停止和镜像切换。部署配方与固定入口已提供；不能用 Windows TestClient 代替 Linux 目标部署。
4. 生产发布根、发布人员密钥分离、真实 HTTPS 更新源、限流/重定向和长下载断点续传联调。测试发布根仅用于隔离证据，不随程序建立生产信任。
5. 实际原生托盘/菜单交互、远程客户端升级对话框及取消、进程崩溃/断电全矩阵。CLI GUI 冒烟和独立探针是运行证据，不能等同于完整人工操作验收。
6. 大批历史全类型资料、复杂跨记录引用、长期离线设备和大附件的规模验收。单个聚合 32 MiB、控制清单 8 MiB，当前选择长期保留墓碑与控制记录；超限停写。升级文件已提供 30 天保留清理，同步历史的自动受控归档仍未提供。
7. 已开放写入后的自动逆向迁移没有实现；当前按 PRD 允许的保守路径保存现状并明确阻止覆盖，需按具体未来迁移设计逆向方案。多组件升级顺序算法已测试，真实不同协议版本的滚动升级仍需目标环境验证。

两张新增验收清单保持既定状态枚举：同步 19 项通过、13 项阻塞；升级 21 项通过、11 项阻塞。阻塞行记录已验证部分与缺少条件，不把两组需求标为全部验收通过。
