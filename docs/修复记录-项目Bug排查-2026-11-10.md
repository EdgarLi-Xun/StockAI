## 排查经验与范围

1. 本项目 `vue-tsc -b` 可以通过，但 Vite 随后仍可能因动态 CSS 引用缺失而失败。入口或样式改动必须验证实际构建，类型检查不足以证明可运行。
2. 切换对象时仅检查 ID 不足以防止 A → B → A 的请求乱序；需要独立递增序号，同时约束当前页面和对象。成功、失败和加载结束三个路径都要检查请求是否仍有效。
3. 此 Windows 沙箱会使 Python 的 `socket._fallback_socketpair` 阻塞，表现为 FastAPI TestClient 在创建 asyncio 循环时停住。通过 faulthandler 确认堆栈后，在允许本机回环的执行环境重跑，避免误判为业务死锁。
4. gstack 辅助脚本无法在当前沙箱启动，本轮以项目原生构建、测试命令和本记录保留证据与经验。
