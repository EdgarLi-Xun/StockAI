# StockAI 3.2.26

2026-11-21 正式版。

## 本次更新

- 界面视觉精修：卡片层级、圆角、阴影、排版和交互反馈更统一，深色模式下图表、设置页、AI 助手面板与确认框的配色保持一致。
- 更新应用图标。

## 下载

- Windows 10/11 x64 安装包 `StockAI-3.2.26-Setup.exe`。
- 独立 Web 部署包 `StockAI-3.2.26-Public.zip` 和独立同步 Hub 部署包 `StockAI-3.2.26-Hub.zip`。
- 每个包附同名 `.sha256`。安装包另附构建元数据，两个 ZIP 内含逐文件校验清单。
- 已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。Web 和 Hub 通过各自的部署流程更新。
