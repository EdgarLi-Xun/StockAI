# StockAI 3.2.5

2026-11-05，正式版。此次修正桌面更新的操作流程。

## 桌面更新

在「同步与版本 → 关于与升级」检查到新版后，点击「下载并准备安装」。程序会依次准备计划、下载、核对 SHA-256 和检查安装条件，显示下载进度；预检完成后，由本人确认退出并安装。

下载可以暂停、续传；暂停时保留进度，续传成功后清除旧错误。已验证的包可直接继续预检。校验失败或暂停时不会继续安装，预检存在未保存编辑等阻断项时会保留提示。离开页面会停止该页面的进度轮询和后续自动步骤。安装仍由明确的确认按钮触发。

旧版界面若只提示「已准备本机安装计划」，请在下方计划区域继续点击「下载并验证」和安装预检，再确认安装本版。旧版程序内置的界面需要通过本次升级更换，之后才使用自动串联的流程。

## 下载

- Windows 10/11 x64：`StockAI-3.2.5-Setup.exe`。
- 独立 Web：`StockAI-3.2.5-Public.zip`；独立同步 Hub：`StockAI-3.2.5-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。Web 与 Hub 保留各自部署流程。

## 验证范围

前端共 66 项回归，其中 12 项覆盖自动更新流程、下载进度、重复点击、失败与暂停、续传、旧响应、预检阻断、页面卸载、目标切换与 Web 模式。另执行生产构建、冻结程序和 Qt 页面检查，并按原始字节核对三份发布校验文件。

详细构建结果与验证统计见 GitHub Release。验证使用独立临时工作区，不触发正式个人环境的安装或重启。
