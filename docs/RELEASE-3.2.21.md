# StockAI 3.2.21

2026-11-17，正式版。此次整理研究页面，并允许清空模型用量上限。

## 模型用量

每日、每月上限可以清空。清空表示不设上限。填写 0 仍表示暂停。保存失败时，草稿和版本号保持不动。

## 研究页面

研究报告先展示结论。研究日志、条件提醒、实验记录和数据问题的标题、日期与状态更清楚。

## 下载

- Windows 10/11 x64：`StockAI-3.2.21-Setup.exe`。
- 独立 Web：`StockAI-3.2.21-Public.zip`；独立同步 Hub：`StockAI-3.2.21-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
