# StockAI 3.2.16

2026-11-11，正式版。此次补上价格规则在日历恢复和同步后的处理。

## 价格规则

交易日历暂时不可用时，规则只记下跳过原因。日历恢复后仍会判断当天，不会把这次跳过当成已经处理过。

数量、均线周期和成功次数上限必须是整数。小数不再被截断后保存。

同步过来的规则委托会改接到本机规则。停止规则并撤单时，仍能撤掉这些待成交委托。

## 确认操作

确认框和表单不再因为点到外侧遮罩而关闭。请使用取消或关闭按钮。

## 桌面调试

调试桌面程序时，升级成功后仍留在当前进程。

## 下载

- Windows 10/11 x64：`StockAI-3.2.16-Setup.exe`。
- 独立 Web：`StockAI-3.2.16-Public.zip`；独立同步 Hub：`StockAI-3.2.16-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
