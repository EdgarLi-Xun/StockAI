# StockAI 3.2.22

2026-11-20 正式版。

## 本次更新

- 切换模拟账户时，组合风险页会立即清除上一账户的估值。即使新账户读取失败，也不会显示旧账户的现金和持仓。
- 组合风险页集中展示总权益、现金、持仓和回撤，估值历史与行业分布各自成区。
- 模拟交易页优先展示账户、模拟委托和现金流水，价格规则可以按需展开。
- 任务中心将执行记录和日志放在前面。自动计划可折叠，筛选无结果时可以一键清除条件。

## 下载

- Windows 10/11 x64 安装包 `StockAI-3.2.22-Setup.exe`。
- 独立 Web 部署包 `StockAI-3.2.22-Public.zip` 和独立同步 Hub 部署包 `StockAI-3.2.22-Hub.zip`。
- 每个包附同名 `.sha256`。安装包另附构建元数据，两个 ZIP 内含逐文件校验清单。
- 已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。Web 和 Hub 通过各自的部署流程更新。
