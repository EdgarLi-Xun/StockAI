# 公网多用户与模型接入验证记录

记录日期：2026-11-01，Asia/Shanghai。公网模块内部版本为 3.0.0，随仓库首次 GitHub Release v2.0.0 提供源码，独立于 Windows 本地入口与数据。

## 验证方法

通过 `tests/test_cloud.py` 及共用的隔离测试验证行为；网络和模型协议使用受控替身，不需要真实 API Key。age 加密往返测试在本机工具可用时执行，缺少时由 pytest 明确标记跳过。最终运行结果、环境和发行包校验见 [首发验证记录](RELEASE-2.0.0.md)。

## 自动测试覆盖

| 范围 | 具体覆盖 |
| --- | --- |
| 身份与会话 | 邀请码单次使用与竞争注册、有效期与撤销、邮箱验证、密码重置、会话撤销、CSRF、正式环境 Cookie |
| 用户隔离 | 个人报告及导出、模拟账户、回测与模型配置的访问边界；管理员不自动获得他人的个人研究内容 |
| 模型配置 | 用户归属、密文绑定、默认配置切换、提交任务时固定版本、禁用与撤销授权后禁止发送 |
| 输入与输出 | 模型输入字段白名单、身份与备注排除、可选资金/逐笔授权、输出结构、来源与定性事实边界、拒绝明文 Key 回显与请求标识泄漏 |
| 模型协议 | MiniMax 请求格式与错误分类、服务器 Ollama 地址限制、不安全地址与混合 DNS 地址拒绝 |
| 重试与恢复 | 限流/临时故障最多重试一次、额度/密钥错误不重试、不确定发送与重启不重复请求、规则降级 |
| 调度与并发 | 默认自动化关闭、仅当天补跑、20 用户公平队列、两个执行槽、不同用户凭据不串用 |
| 报告归档 | 规则报告补充 AI 时保留旧版本、固定原始事实快照、发布写回与注销竞争处理 |
| 模拟交易 | 个人账户成交、幂等账本、资金与持仓归属 |
| 备份与注销 | age 加密往返、注销记录重放、旧凭据与会话失效、下载再认证/单次授权、保留期、损坏密文拒绝 |
| 迁移与恢复 | 本地副本迁移、目标用户归属、源目录不改写、中断目录切换回滚、缺失权威记录拒绝恢复 |
| 运行门槛 | SQLite WAL-reset 修复版本检查；显式开发模式对旧 SQLite 使用 DELETE journal |

公网前端执行 `npm --prefix frontend run build:public`，同时进行 Vue / TypeScript 类型检查并生成独立的 `frontend/dist-public/`。

## 尚需在目标环境验证

- Linux x86_64 上从零构建并启动当前 Docker Compose 镜像、持久卷 UID/GID 权限及健康检查。
- 实际域名解析、Caddy 证书签发、HTTPS 与公网访问。
- 真实 SMTP 的注册验证和密码重置邮件送达。
- 用户自己的 MiniMax / OpenAI 兼容 Key、实际可用模型、配额、计费与响应质量。
- 实际服务器 Ollama、20 个真实使用者的持续负载、停机与运维恢复演练。

上述外部条件没有计入自动测试通过结论。正式部署步骤与数据目录保管方式见 [公网部署指南](../deploy/cloud/README.md)。
