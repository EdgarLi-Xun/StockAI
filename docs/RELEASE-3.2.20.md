# StockAI 3.2.20

2026-11-14，正式版。此次避免一只报价异常拖垮整份自选。

## 自选预算

某只证券的价格对不齐最小变动价位时，只留空这只的预算，并在排除原因里记下。其余自选仍正常返回。有行情但无法估算时，列表显示「无法估算」。

## 研究页面

候选、研究报告和模型配置的空状态改为更短的说明。报告列表按日期和标题排列。

## 外观

外观设置的浅色预览改回暖纸色。效果预览与主题选项分开。

## 下载

- Windows 10/11 x64：`StockAI-3.2.20-Setup.exe`。
- 独立 Web：`StockAI-3.2.20-Public.zip`；独立同步 Hub：`StockAI-3.2.20-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
