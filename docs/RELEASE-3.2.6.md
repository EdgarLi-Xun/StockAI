# StockAI 3.2.6

2026-11-05，正式版。此次加入想法池评审，并让邮件账号和助手里的研究动作留在工作台内完成。

## 想法池

工作台新增「想法池」。已保存的想法进入早报评审，按固定关卡写明过关或死因；周度复盘汇总本周死因。点名比特币或以太坊的内容会被拒绝，公开资料不足三条时补齐也会跳过这类内容。评审不下单，也不编写自动交易。

## 工作台内的研究动作

助手可以准备条件提醒、新的研究判断、研究课题和实验方案，先展示，由本人点击后才写入。提醒的价格和涨跌幅使用本人给出的阈值。实验须挂到已有课题，没有课题时先准备课题。查看已经保存的回测或实验不再走新建方案，避免回答超出上下文。

## 邮件发送

管理员在「设置 → 邮件发送」保存发信账号。预设包含 QQ、163、126、Gmail 和 Outlook，也可以按服务商填写 SMTP 服务器、端口和加密方式。授权码加密保存。验证邮件和条件提醒邮件优先使用已保存账号，没有保存记录时回退到部署环境变量。站点未配置邮件时，条件提醒仍使用站内通知。

## 下载

- Windows 10/11 x64：`StockAI-3.2.6-Setup.exe`。
- 独立 Web：`StockAI-3.2.6-Public.zip`；独立同步 Hub：`StockAI-3.2.6-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
