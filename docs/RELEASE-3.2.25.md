# StockAI 3.2.25

2026-11-21 正式版。

## 本次更新

- 官方公告查询失败或停复牌附件未读时，证券详情和报告会标明核验缺口，相关证券在重新核验前无法入选研究候选。预定停牌在生效前即可追溯到官方公告。
- 共享行情和公告采集完全失败时，系统会延后重试原任务。任务中心显示下次重试时间和已执行次数，并保留原采集参数。

## 下载

- Windows 10/11 x64 安装包 `StockAI-3.2.25-Setup.exe`。
- 独立 Web 部署包 `StockAI-3.2.25-Public.zip` 和独立同步 Hub 部署包 `StockAI-3.2.25-Hub.zip`。
- 每个包附同名 `.sha256`。安装包另附构建元数据，两个 ZIP 内含逐文件校验清单。
- 已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。Web 和 Hub 通过各自的部署流程更新。
