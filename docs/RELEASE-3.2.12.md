# StockAI 3.2.12

2026-11-10，正式版。此次收紧工作台文案和浅色外观。

## 文案与登录页

页面标题和空状态改为更短的说明。登录页改为「行情。研究。记录与复盘。」

## 浅色外观

浅色主题背景改为暖纸色。标题使用衬线字体，面板圆角更紧凑。导航与总览指标卡排版更紧凑。

## 下载

- Windows 10/11 x64：`StockAI-3.2.12-Setup.exe`。
- 独立 Web：`StockAI-3.2.12-Public.zip`；独立同步 Hub：`StockAI-3.2.12-Hub.zip`。
- 每个包附同名 `.sha256`，校验文件统一使用 LF；安装包另附构建元数据，两个 ZIP 含逐文件校验清单。
- 安装目录与研究工作区分开，沿用现有每用户安装方式。已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。
