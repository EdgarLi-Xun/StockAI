# StockAI 3.2.24

2026-11-21 正式版。

## 本次更新

- 证券详情和研究报告展示上交所停复牌记录及巨潮资讯公告的来源。交易状态按公告和交易所记录的生效时间更新。
- 自动报告遇到暂时的数据访问或连接错误时，会在原任务下延后重试。任务中心显示下次重试时间和已执行次数。
- 完整版报告按上金所金银日收盘价计算年化波动率，并展示金银与矿业股、黄金 ETF 的同期及滞后相关性。样本不足时标明缺口。

## 下载

- Windows 10/11 x64 安装包 `StockAI-3.2.24-Setup.exe`。
- 独立 Web 部署包 `StockAI-3.2.24-Public.zip` 和独立同步 Hub 部署包 `StockAI-3.2.24-Hub.zip`。
- 每个包附同名 `.sha256`。安装包另附构建元数据，两个 ZIP 内含逐文件校验清单。
- 已安装的桌面版可在「同步与版本 → 关于与升级」检查本版。Web 和 Hub 通过各自的部署流程更新。
